# AI Sign Language Translator

This project is a continuation and improvement of the work from the [WLASL repository](https://github.com/dxli94/WLASL).

## Key Features

*   **Improved Accuracy:** The AI model has been retrained and re-validated, resulting in higher accuracy for sign language translation.
*   **Live Translation:** The program can translate sign language in real-time from a camera or webcam feed into words and sentences.
*   **NLP Integration:** Natural Language Processing (NLP) is used to form coherent sentences from the translated words.
*   **Future-Proof:** This project is under continuous development with plans for future improvements.

## Requirements

*   **CUDA Support:** A CUDA-enabled GPU is required to run the program.
*   **Camera/Webcam:** A camera or webcam is necessary for live translation.
